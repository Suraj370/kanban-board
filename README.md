# Kanban Board

## Description
A Kanban board application that helps manage tasks and projects using the Kanban methodology. Users can create, update, and delete tasks, as well as organize them into different columns representing various stages of completion.

## Features
- Create, update, and delete tasks
- Organize tasks into columns
- Drag and drop functionality for task management
- User-friendly interface
